# GreenSpace WebOS

GreenSpace WebOS is a browser-based desktop environment created for the Hack Club WebOS 1 mission.

The project is being built incrementally. Each development session adds one focused group of features while improving the work from earlier sessions.

## Current status

Hour 1 is complete.

The project currently provides:

- A custom desktop background
- Three desktop application icons
- A Welcome application window
- A taskbar
- A Start button placeholder
- A running application button
- A system tray
- A live clock and date
- A responsive layout for smaller screens

The application windows are not draggable yet. Window interaction will be added during later development hours.

## Applications

### Welcome

The Welcome application introduces the WebOS project and displays the current system status.

### Notes

The Notes icon is visible, but its application has not been built yet.

### Nature

The Nature icon is visible, but its application has not been built yet.
